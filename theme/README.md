# TIMKIEM / AIHUB Blogger theme assets

Static CSS/JS extracted from `AIHUB-theme-UPLOAD.xml` so the Blogger theme stays under the **2MB** save limit and pages load faster.

## Serve via jsDelivr (not GitHub raw)

```
https://cdn.jsdelivr.net/gh/kkymljnk/timkiem-blogger-assets@vYYYYMMDD/theme/FILE
```

Optional mirror (if configured): `https://cdn.www.timkiem.app/assets/theme/FILE?v=YYYYMMDD`

## Files

| File | Role |
|------|------|
| `qcx-polish.css` | polish + carrd + equal-cards + reference footer |
| `qcx-smart-media.css` | media / article chrome |
| `qcx-runtime.js` | carrd motion + mobile nav + lightbox + equal-cards |
| `qcx-smart-runtime.js` | smart runtime |
| `qcx-secure-resource.js` | vault / unlock |
| `qcx-layout-rescue.js` | feed rescue / rebuild |
| `qcx-brand-mark.png` | brand mark (replaces inline base64) |
